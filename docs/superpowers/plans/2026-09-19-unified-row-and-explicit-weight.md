# Unified Exercise Row, Explicit Reps and Weight — Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** One row layout for the saved-workout editor and Today's workout (sets chip, link nodes on a rail, reps and weight steppers), backed by per-row explicit/auto reps and weight, with a saved workout able to store an explicit weight.

**Architecture:** Pins live on the row: `PlannedExercise.repsPinned/weightPinned` and `SavedWorkoutEntry.reps/weight` (null = auto). `WorkoutPlanner.withWeight` is the single pricing rule and honours the pins, which makes the one-rep-max override map (`WorkoutPlan.exerciseOverrides`, `WorkoutPlanner.exerciseE1rmOverrides`, `buildPlanner`'s third parameter) dead; it is deleted. The UI is rebuilt from three shared composables in `ui/components/CircuitChrome.kt`.

**Tech Stack:** Kotlin, Jetpack Compose Material3, Room (DB stays v21), `sh.calvin.reorderable`, jj.

**Spec:** `docs/superpowers/specs/2026-09-19-unified-row-and-explicit-weight-design.md`

    private fun withWeight(pe: PlannedExercise, sessionReps: Int): PlannedExercise {
        if (pe.exercise.isTimed) { /* unchanged, plus repsPinned = false, weightPinned = false */ }
        val reps = if (pe.repsPinned) pe.sessionReps else sessionReps
        val suggested = weightForExercise(pe.exercise, reps)
        // A weight can only be pinned where there is a weight to prescribe.
        val pinned = pe.weightPinned && suggested > 0f
        val weight = if (pinned) pe.sessionWeight else suggested
        val warmups = computeWarmupSets(weight, pe.exercise)
        return pe.copy(
            sessionWeight = weight, sessionReps = reps, weightPinned = pinned,
            warmupSets = warmups, estimatedSeconds = durationOf(pe, reps, warmups),
        )
    }

    /** Prices [pe] for a session at [sessionReps], honouring its pins. */
    fun reprice(pe: PlannedExercise, sessionReps: Int): PlannedExercise = withWeight(pe, sessionReps)

    /** The prescription for [exercise] at [reps], kg; 0 when it cannot be loaded. */
    fun suggestedWeight(exercise: Exercise, reps: Int): Float = weightForExercise(exercise, reps)

    /** Applies [edit] to one preview row and re-prices it through the planner, honouring its pins. */
    private fun editRow(exerciseId: Long, edit: (PlannedExercise) -> PlannedExercise) {
        val preview = _state.value as? WorkoutState.PlanPreview ?: return
        val p = planner ?: return
        val rows = preview.plan.exercises.map {
            if (it.exercise.id == exerciseId) p.reprice(edit(it), preview.plan.sessionReps) else it
        }
        if (rows == preview.plan.exercises) return

    fun adjustExerciseWeight(exerciseId: Long, delta: Float) = editRow(exerciseId) { pe ->
